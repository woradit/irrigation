# ระบบให้น้ำเพื่อการเกษตร

บทเรียนออนไลน์แบบโต้ตอบ 6 บท สำหรับฝึกออกแบบระบบให้น้ำแปลงเกษตร
ตั้งแต่ความต้องการน้ำของพืชไปจนถึงการเลือกเครื่องสูบน้ำ
เนื้อหาเรียบเรียงจากเอกสารอบรม “ระบบให้น้ำเพื่อการเกษตร ระดับเบื้องต้น”
ของสมาคมวิศวกรรมเกษตรแห่งประเทศไทย (วิทยากร ชีรวรรธก์ มั่นกิจ)

## โครงสร้างไฟล์

```
index.html            หน้าแรก รวมลิงก์ทุกบท
ch1-water-need.html   บทที่ 1 ความต้องการน้ำของพืช
ch2-systems.html      บทที่ 2 ระบบให้น้ำพืช
ch3-pipes.html        บทที่ 3 ท่อสำหรับระบบให้น้ำ
ch4-friction.html     บทที่ 4 แรงเสียดทานกับขนาดท่อ
ch5-layout.html       บทที่ 5 การแบ่งแปลงและวางแนวท่อ
ch6-pumps.html        บทที่ 6 เครื่องสูบน้ำเพื่อการเกษตร
assets/style.css      สไตล์ที่ใช้ร่วมกันทุกหน้า (สี ฟอนต์ โหมดมืด)
assets/favicon.svg    ไอคอนเว็บ
.nojekyll             บอก GitHub Pages ให้เสิร์ฟไฟล์ตรงๆ ไม่ต้องผ่าน Jekyll
```

เป็นเว็บแบบ static ล้วน ไม่ต้อง build ไม่มี dependency (ฟอนต์โหลดจาก Google Fonts)

## ดูบนเครื่องตัวเอง

ดับเบิลคลิกเปิด `index.html` ได้เลย หรือรันเซิร์ฟเวอร์เล็กๆ:

```sh
python3 -m http.server 8000
# แล้วเปิด http://localhost:8000
```

## เผยแพร่ด้วย GitHub Pages

1. สร้าง repository ใหม่บน GitHub แล้ว push ไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป
   ```sh
   git init
   git add .
   git commit -m "Initial site"
   git branch -M main
   git remote add origin https://github.com/<ชื่อผู้ใช้>/<ชื่อ-repo>.git
   git push -u origin main
   ```
2. ใน repository ไปที่ **Settings → Pages**
3. ตรง **Build and deployment** เลือก Source เป็น **Deploy from a branch**
   แล้วเลือก Branch `main` และโฟลเดอร์ `/ (root)` กด Save
4. รอประมาณ 1–2 นาที เว็บจะขึ้นที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`

ลิงก์ระหว่างหน้าทั้งหมดเป็นแบบ relative จึงใช้ได้ทั้งบนเครื่องและบน GitHub Pages
ไม่ว่าจะตั้งชื่อ repository ว่าอะไร

## หมายเหตุ

- เครื่องคำนวณในเว็บใช้ประกอบการเรียนเท่านั้น การออกแบบจริงควรตรวจสอบกับแคตตาล็อกผู้ผลิตและวิศวกร
- ตาราง Ep ในต้นฉบับมีค่าเดือนสิงหาคมของสถานีลำดับ 43–60 ผิดพลาด (เป็น 3.24 เหมือนกันหมด)
  หน้าเว็บบทที่ 1 ทำเครื่องหมายและเตือนไว้แล้ว
- ถ้าจะเผยแพร่สาธารณะ ควรขออนุญาตเจ้าของเอกสารต้นฉบับก่อน
